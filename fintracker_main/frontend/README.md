# FinTracker Frontend

A React TypeScript frontend for the FinTracker API.

## Setup

1. Install dependencies:
   ```
   npm install
   ```

2. Start the development server:
   ```
   npm run dev
   ```

3. Make sure the backend is running on `http://localhost:8000`.

## Features

- View list of users
- View user details including profile and transactions
- Create new users
- Add transactions to users
- Update user profiles
- Delete users and transactions
